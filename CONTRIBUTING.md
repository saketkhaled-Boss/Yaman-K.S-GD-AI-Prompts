# Contributing to Yaman AI Prompts

Thank you for your interest in contributing!

## How to Contribute

1. Fork this repository.
2. Create a new branch.
3. Add or improve prompts.
4. Follow the Prompt Template.
5. Submit a Pull Request.

---

## Prompt Requirements

- Original work
- Clear structure
- English language
- Tested before publishing
- Include metadata.yml
- Include preview image if possible

---

## Code Style

- Markdown formatting
- Lowercase folder names
- Hyphen-separated file names

Example:

book-cover-prompt

not

BookCoverPrompt

---

Happy Prompt Engineering!
